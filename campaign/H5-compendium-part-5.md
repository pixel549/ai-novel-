## How to use this file

Same job `H1`–`H4` did for Regions I–IV, now for the last region, and the
shortest of the five on purpose — the same restraint `G5` held for the
bestiary applies here. Region V has no new thin site, no armed antagonist,
and a lead web built almost entirely out of ledgers, memory, and one old
woman's own record-keeping; a Compendium for a Part this quiet should read
like one. What follows is the handful of documentary objects Reveals A–C
actually turn on (an innkeeper's own account books, the retainer itself, the
First House's own archive, a marker in the Named Ground, Prynne's travelling
case), the coast's own version of the four native-Arcana gifts `H1` already
named, a Chalice-Gifts section that closes the question every earlier `H`
file carried forward, and the thinnest weapons register in the campaign.
Hand a PC-facing item description to players directly; keep the Arcana and
Chalice-Gifts sections DM-only where noted, same split `PLAN.md` draws
between `B` (players) and everything else (DM).

**Session default — D-40 (`DECISIONS.md`).** None of the specific items or
the Chalice-Gifts section's final framing are fixed by an earlier file.
`R5a` and `R5b` each name or imply an object this file had to build out
(Catchpole's own books, the retainer, the First House's ledgers, a Named
Ground marker, Prynne's case) — logged here rather than decided silently,
the same way `G5` invented its archetypes.

## Arcana at the Old Coast

Per canon §5 and `C2`'s Arcana practitioners entry, the coast's own ceiling
is identical to every other region's — the same four gifts, the same hard
limits, nowhere in the Commonwealth does the gift itself get stronger. What
changes, per `G5`'s own Hollowmere instance, is not how guarded it's kept
but why it doesn't need to be: isolation, not institutional distance, is
what's left it unnoticed, and this file's own entry follows that framing
rather than extending the escalating caution `G1`–`G4` built.

- **Hearth-, Ease-, Mend-, and Find-work.** Identical in kind and ceiling to
  `H1`'s own entries; see that file for the full description of each.
  Mend-work's hard limit (no regrowth, no disease cure, inherited from
  Maria's own per canon §2) binds here exactly as it does everywhere else.
- **What's different here.** Per `G5`, the Hollowmere instance plays its
  ward openly, demonstrated for a party that asks kindly — the fifth and
  last regional break from `G1`–`G4`'s own pattern of getting more guarded
  each time, and the only one of the five built on safety rather than its
  absence. A DM running this archetype should let that openness read as a
  product of distance, never of the Church's reach actually thinning —
  `R5b` §6 settles that the moment Prynne is dispatched at all.
- **Find-work and the lead web.** As in every earlier region, a PC with
  this gift gets no mechanical shortcut to any of `R5b`'s three reveals —
  Routes exist enough without one. At most, colour: a character with this
  knack might feel, once, a "pull" toward the First House itself long
  before Reveal B gets there properly, a feeling a DM can let land as
  atmosphere without it standing in for any route `R5b` already built.

`(SYS?)` tier: all four stay low-tier and non-combat, same as `H1`–`H4`;
nothing on this coast raises the ceiling.

## Chalice-Gifts

**DM-only.** `H1` kept this section inert because no thin site existed
anywhere yet. `H2` made it a pointer to a site live and ahead. `H3` held
two sites behind and one still ahead. `H4` found one site sitting inside
its own region's geography. This file is the last shape the section takes,
and the simplest: **`T1`, `T2`, and `T3` are all now behind a Part V
party, and this region opens nothing new.** Per `R5b`'s own D-27 call 4,
Region V has no Salts loop at all — the campaign's last Part proves its
own thesis by not needing one, every ending won or lost entirely on the
surface, with nothing a chalice could have made easier.

What this section exists to do, for the last time, is keep three things
straight for whoever is running this Part with the Compendium open:

1. **A PC may already carry a chalice gift from `T1`, `T2`, or `T3`.** If
   so, it travels into Region V unchanged. Nothing on the Old Coast
   explains, revises, adds to, or costs it further — read `T1`/`T2`/`T3`
   and `S1` directly for how any of the three gifts was built and what it
   still costs.
2. **Nothing in this Part opens a new chalice, anywhere.** Not Hollowmere,
   not the Tide Flats, not the First House itself — per `R5a`'s own DM
   notes, Fallow Head ran no active ascension work even in its own working
   years and has had none within living memory. This file doesn't invent
   an exception on the campaign's last stretch to make the Compendium feel
   fuller.
3. **A party that finishes the campaign having never found `T1`, `T2`, or
   `T3` has lost nothing this file considers a reward**, per `C3`'s own
   standing instruction, stated here for the last time rather than carried
   forward again.

`(SYS?)`: no stat block accompanies any of this, for the same reason every
earlier `H` file gave — there is nothing left here to assign.

## Items

Ordinary and documentary objects the Part's lead web already assumes
exist. Player-facing except where marked.

**Wren Catchpole's account books.** The Anchorage's own ledger, itemised
the way Edie kept hers (`source-bible.md` → Objects; `R5a`) — the fifth and
last instance of the convention `D1` began with Nessa Beddoe's slate and
`H2`–`H4` continued with Ress Tannery's rooming book, the Waiting House's
slate, and the Night Siding's arrivals board. Unlike any of the four
before it, this one holds a record going back further than any living
memory in the village — the retainer entered quarterly, unbroken, for
longer than the books themselves go. A DM can let a party earn a look at
these cold, the way `R5a`'s own Secrets entry describes; reading them is
Reveal A, Route 1, not a separate obstacle.

**The quarterly retainer.** A sealed purse, delivered by hand on a
schedule nobody in Hollowmere has ever had to ask about twice — never
itemised past "the usual," never written down anywhere as coming from "the
House" (`R5a`). Physically unremarkable; its entire weight is in what
Catchpole's own books say about its history, not in the coin itself. A
party that intercepts or asks about a live delivery learns nothing the
books don't already show more plainly.

**The First House's ledgers.** Shelf after shelf, bound by decade, the
single largest documentary object in the campaign — every name, date, and
documented failure the Fourth Mercy has produced in sixty years, in a hand
that changes only a few times across all of them, Vance's own for the most
recent third (`R5a`). Not a prop to summarise: per `R5b`'s own Reveal C,
what's actually read inside is the Part's real reveal, and a DM should let
a party read an entry or two directly once Vance opens the archive, the
same instruction `H1`–`H4` all give their own central documents. This is
where Vantry's own partial record (`hooks.md` #3) and Greymere's manifest
(`R4b`) are shown to be fragments of something far larger, not separate
discoveries.

**A Named Ground marker.** A plain stone, numbered and dated, nothing else
cut into it — one of row upon row behind the First House, each
cross-referenced by that same number to an entry in the ledgers inside
(`R5a`, "The Named Ground"). Not a document a party takes away; it stays
fixed to the ground, read in place, the way `R2a`'s shelter roll and
`R4a`'s parish noticeboard both stay fixed to theirs. Whether any specific
marker answers a specific name a table has carried since an earlier Part
is the table's own continuity to decide, per `R5a`/`R5b`, not this file's
to assume.

**Brother Prynne's travelling case.** A battered case of blank forms,
carried on the next available rail connection the moment word of an
outside party reaches Carrowgate (`R5b` → "The Registrar's Visit"). Prop
only; its function in play is exactly what Prynne says it's for — recovery
if possible, cataloguing if not — and a DM describing it concretely
("he sets the case down, unlatches it, takes out a form already
half-filled") does more work than narrating his intentions in full.

## Weapons

The thinnest register in the campaign, on purpose. Region V's only
possible antagonist encounter (`R5b` §6) is a conversation Prynne is
constitutionally built never to turn into a fight, and Vance has carried
nothing sharper than a garden trowel in sixty years. This file invents no
coast-specific tool the way `H1`–`H4` each named one for their own
region — Hollowmere's own fishing gear has nothing a scene in this Part
ever reaches for, and inventing an entry here would be reaching for
texture Region V doesn't need.

**What the Old Coast carries: nothing.** Restated from `H2`–`H4`, extended
here to its furthest point: no Church face in this Part — not Vance, not
Prynne, not anyone a table meets at Hollowmere or Fallow Head — carries or
draws a weapon of any kind. The institution's menace lives entirely in
content, never in staging, same as everywhere else in the campaign, and
the campaign's own last antagonist is the clearest demonstration of it yet.

**An Attrition-surplus revolver.** The same Commonwealth-wide surplus
`H1`–`H4` already describe (canon §5) — plain, worn, and no less
unremarkable to own on this coast than anywhere else. A Hollowmere boat-hand
with a reason to keep one fits this village exactly as well as it fits any
earlier region. `(SYS?)` tier: the one weapon in this file capable of
lethal force at range — treat every appearance as a serious escalation,
never as flavour.

**A trench knife.** Attrition-era, double-edged, carried quietly by
veterans who don't talk about where they got it — identical to every
earlier region's own entry, no regional variant needed. `(SYS?)` tier:
low-to-mid, close range only.

## DM Notes

**Nothing above needs a fight, more than any Part so far.** Per `G5`'s own
standing note: this region's entire register of pressure is an innkeeper's
slow trust, an old woman's own question, and a Registrar who files rather
than fights. A DM reaching for the revolver or the trench knife in this
Part should check first whether the scene actually called for one, or
whether an item entry just happened to exist.

**Items are props, not a reward track.** Same restraint `H1`–`H4` all
held: no item above makes a PC mechanically stronger. The First House's
ledgers especially are not loot — what a party gains from them is
information and a choice among `R5b`'s five endings, never a mechanical
benefit.

**The Chalice-Gifts section closes a question five files kept open.** If a
player asks whether their character can drink from a chalice this Part,
the honest answer is no — not here, not anywhere left in the campaign —
and if that same player already carries a gift from `T1`, `T2`, or `T3`,
this file changes nothing about it. The campaign ends exactly as `R5b`
built it: won or lost on the surface.

**How the novel's three appear.** No change from `R5a`/`R5b`'s own note:
nothing above is a vehicle for giving Lloyd, Maria, or Edie a scene in this
Part. None of the three appear here, even restrictively, and this file
invents no reason to change that at the very end of the campaign.
