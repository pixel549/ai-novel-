# campaign/system

Put the binding game documents here (markdown preferred; .docx is fine but
sessions read markdown more reliably):

- Core ruleset (v7 or later)
- Design bible / monster manual (v2.5 or later)
- Dev log (known gaps, untested rules)
- Character sheet template

Scheduled sessions treat everything in this folder as binding and prefer it
over any number or term they might otherwise guess. If this folder is empty,
campaign files use archetype and tier only and mark numbers `(SYS?)`.
