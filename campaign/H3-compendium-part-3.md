## How to use this file

Same job `H1` and `H2` did for Regions I and II, now for Region III, and
the shortest of the three on purpose — the same restraint `G3` held for
the bestiary applies here. Region III has no Fourth Mercy connection, no
thin site, and an antagonist who never once reaches for a weapon; a
Compendium for a Part built entirely on paperwork should read like one.
What follows is the paper trail Reveals A–C actually turn on (a case file,
a filing, a maintenance contract, a public record, a settlement), the
capital's own sharper edge on the four native-Arcana gifts `H1` already
named, a Chalice-Gifts section kept inert for a region with no site of its
own, and a weapons register deliberately thinner than either predecessor's.
Hand a PC-facing item description to players directly; keep the Arcana and
Chalice-Gifts sections DM-only where noted, same split `PLAN.md` draws
between `B` (players) and everything else (DM).

**Session default — D-36 (`DECISIONS.md`).** None of the specific items,
the vestment-thread frame's placement in this file, the weapons section's
deliberate thinness, or the Chalice-Gifts section's "behind, not ahead"
framing are fixed by an earlier file. `R3a` and `R3b` each name or imply a
document this file had to build out (the closed file itself, the
expedited filing, the carpet men's own contract, the appropriations
record, the settlement draft) — logged here rather than decided silently,
the same way `G3` invented its archetypes.

## Arcana in Carrowgate

Per canon §5 and `C2`'s Arcana practitioners entry, the capital raises the
cost of being noticed without raising the ceiling — exactly the pattern
`H2` already found moving from the valley to Vantry, one step further
along. The four gifts below are the same four `H1` named; this file
doesn't invent new categories, only restates Carrowgate's own sharper
edge.

- **Hearth-, Ease-, Mend-, and Find-work.** Identical in kind and ceiling
  to `H1`'s own entries; see that file for the full description of each.
  Mend-work's hard limit (no regrowth, no disease cure, inherited from
  Maria's own per canon §2) binds here exactly as it does everywhere else.
- **What's different here.** Per `G3`'s Boarding-District Reader, a
  Carrowgate practitioner keeps the gift smaller and better-hidden than
  either earlier region's version needed to — a city that files everything
  it touches (the Indemnity Office's own request slips, the Senate's
  committee record) is the single worst place in the campaign to be
  noticed for something unregistered, and the capital's own people have
  drawn that correct conclusion already.
- **Find-work and the lead web.** As in Regions I and II, a PC with this
  gift gets no mechanical shortcut to any of `R3b`'s three reveals — all
  three already have enough routes without one. At most, colour: a
  character who's had this knack since childhood might say, once, that
  the Indemnity Office's own filing room "pulls wrong," the same register
  `H1` and `H2` both allow, never standing in for any of the lead web's
  actual routes.

`(SYS?)` tier: all four stay low-tier and non-combat, same as `H1`/`H2`;
nothing in Carrowgate raises it.

## Chalice-Gifts

**DM-only.** Region III has no thin site — `R3a`, `R3b` §7, and `C3` all
confirm this independently, and `R3b`'s own precedent (declining a Fourth
Mercy Products category per D-23/D-35) is the model this section follows
for the chalice as well: a deliberate absence, stated plainly, not an
oversight.

This is not the same inert section `H1` wrote, because the campaign around
it has moved on since. `T1-the-foundation.md` (Vantry) and
`T2-the-second-day.md` (the Northern Road, between the Larrow Valley and
Vantry) are both built, live, and — per the campaign's own playable
order — **behind** a party reaching Part III, not ahead of them. `T3-the-
standing-cistern.md` sits beneath Lissom Fen in Region IV, still ahead of
where this Part leaves a table; this file does not treat it as reachable
yet, the same order-of-discovery discipline `H2` held when only `T1`
existed.

What follows keeps three things straight for whoever runs this Part with
the Compendium open:

1. **A PC may already carry a chalice gift from `T1` or `T2`.** If so, it
   travels into Region III unchanged. Nothing in Carrowgate explains,
   revises, adds to, or costs it further — this file is not where that
   bookkeeping lives; read `T1`/`T2`/`S1` directly for how the gift was
   built and what it still costs.
2. **Nothing in this Part opens a new chalice, anywhere.** The Sanctum's
   own clean hands (D-23) extend here too: whatever the Church's Carrowgate
   headquarters is, it is not a site where the Salts can be reached, and
   this file doesn't invent an exception to make the Compendium feel
   fuller.
3. **A party that reaches Part III having never found `T1` or `T2` has
   lost nothing this file considers a reward**, per `C3`'s own standing
   instruction, carried forward unchanged.

`(SYS?)`: no stat block accompanies any of this, for the reason `H1` and
`H2` both gave — there is nothing here to assign.

## Items

Ordinary and documentary objects the Part's lead web already assumes
exist. Player-facing except where marked.

**The closed file.** Halvard Crane's own Indemnity case folder — thin,
concluded, "misadventure, Indemnity review session, service passage" in a
clerk's economical hand, a restitution figure entered and initialled, no
further minute attached (`R3b` → Reveal A). A DM can hand a page of this
to players directly once Winifred Sorrel produces it; it's meant to be
read, not summarised, same instruction `H1`/`H2` give their own
documents.

**A civic request slip.** The Indemnity Office's own version of the
obstacle `H2` already named for Vantry's archive: name, date, reason for
request, Sorrel's signature once it's filled correctly (`R3b` → set piece
"The Closed File"). The point, same as `H2`'s, is that almost nobody ever
files one — the slip itself is trivially easy, and a DM should let that
land rather than treating it as a puzzle.

**The expedited-closure filing.** The Valley Trust's solicitors' own
letter asking the Indemnity Office to move Crane's file quickly — on the
firm's letterhead, filed and time-stamped, legally unremarkable sitting
alone (`R3b` → Reveal B, Route 1). The single physical object that, laid
beside the Larrow Valley's own survey-burial paperwork (`R1b`), proves the
same firm's hand behind both.

**The carpet men's maintenance contract.** The cleaning crew's own
service agreement and access log, retained by that same solicitor's firm
— a schedule that happens to put them in the right corridor at the right
time (`R3b` → Reveal B, Route 2, and the "Carpet Men" set piece). Prop
only; what it proves depends entirely on whoever thinks to check it
against the firm's own letterhead.

**The appropriations line.** A single annotated page from the Senate's
own public printed record — no names on it, just a sum large enough to
need a line of its own (`R3b` → Reveal A, Route 3). A DM can let a page,
or a page's own sincere explanation, stand in for a longer committee-record
crawl.

**The vestment-thread frame.** The scrap of torn vestment cloth caught on
a window latch near where Crane died (`source-bible.md` → Objects; canon
ch. 24) — not evidence that would hold up under oath, enough only to point
the obvious question at the Church, and already spent as a frame by the
book's own ending. This file is the first to give it a Compendium entry,
since Region III is the first Part whose own lead web runs directly
through the office that closed Crane's case. A DM handling it in play is
holding the physical remainder of a story already told, not reopening
whether it was true — see DM Notes, and `R3b`'s own warning against
implying Church guilt.

**A settlement draft.** The legal instrument Pell and Vane's solicitors
hand over if the party corners or threatens either man (`R3b` → "What
capture looks like"): drafted, generously sized, structured so accepting
it closes the matter cleanly and pursuing it further afterward looks
litigious rather than righteous. Prop only; its entire function in play is
what it is, not what it does mechanically — handing it to a player
directly is the scene.

**The Waiting House's slate.** Caddock Lowe's own common-room board
(`R3a`) — the third instance of the convention `D1` set with Nessa
Beddoe's slate and `H2` continued with Ress Tannery's rooming book: who's
owed what, who's still waiting on which office, never a number, never
read cold by a PC, since Lowe keeps it in his own shorthand the same way
Nessa and Ress do.

## Weapons

The thinnest register in the Compendium so far, on purpose. Region III's
own antagonist pressure never once reaches for a weapon (`R3b`'s own
tells for Pell and Vane), and the capital's violence, where it exists at
all, is institutional rather than physical. This file doesn't invent a
city-specific melee tool the way `H1` named mine tools or `H2` named mill
and yard tools — Carrowgate's own professionals (clerks, pages,
petitioners) have nothing analogous lying around a committee room worth a
new entry, and inventing one here would be reaching for texture Region
III doesn't need.

**What the Valley Trust carries: paperwork, not weapons.** Per `R3b`'s own
discipline for Pell and Vane — neither lies, neither threatens, and
neither has ever needed to draw anything sharper than a request slip, a
formal appeal, or a drafted settlement. A DM reaching for this file to
arm either man, or the Carpet Men's own cover, has written the Part
wrong in exactly the way `R3b`'s DM Notes already warn against.

**What the Church carries: nothing.** Restated from `H2`, extended here
to the Sanctum's own headquarters: no Church face in this Part, from a
Mercy sister at the bread queue to whoever Brother Wick answers to above
Vail, carries or draws a weapon of any kind. The institution's menace
lives entirely in content, never in staging, same as everywhere else in
the campaign.

**An Attrition-surplus revolver.** The same Commonwealth-wide surplus
`H1` and `H2` already describe (canon §5) — plain, worn, and no less
unremarkable to own in the capital than anywhere else. A Waiting House
tenant or a disillusioned veteran carrying one fits Carrowgate exactly as
well as it fits the valley or the rail yards. `(SYS?)` tier: the one
weapon in this file capable of lethal force at range — treat every
appearance as a serious escalation, never as flavour.

**A trench knife.** Attrition-era, double-edged, carried quietly by
veterans who don't talk about where they got it — identical to `H1`'s and
`H2`'s own entry, no regional variant needed. `(SYS?)` tier: low-to-mid,
close range only.

## DM Notes

**Nothing above needs a fight, more than any Part so far.** Per `G3`'s
own standing note: Region III's entire register of pressure is a clerk
who answers plainly, a tell that routes a question to a form, and a
cleaning crew that never gets any closer than a public street allows. A
DM reaching for the revolver or the trench knife in this Part should
check first whether the scene actually called for one, or whether an item
entry just happened to exist.

**Items are props, not a reward track.** Same restraint `H1` and `H2`
held: no item above makes a PC mechanically stronger. A DM looking for a
"found item" beat should reach for information or standing — a route
opened, a favour owed, per `F1` §6 — not an object from this list.

**The Chalice-Gifts section is inert, and the "behind, not ahead" framing
matters.** If a player asks whether their character can drink from a
chalice this Part, the honest answer is no — not here, not yet, and not
because the Compendium forgot to mention one. If that same player already
carries a gift from `T1` or `T2`, this file changes nothing about it;
don't let Carrowgate's own paperwork become an excuse to re-litigate a
cost `S1` and the relevant `T` file already fixed.

**The vestment-thread frame is a prop, not a loose thread to pull.** Per
`R3b`'s own warning: handling this object in play should never imply the
frame was true, or that the Church had anything to do with Crane's death.
Canon settles that in ch. 24. A DM who lets a table "solve" the frame as
a cover-up has written this item wrong.

**How the novel's three appear.** No change from `R3a`/`R3b`'s own,
most restrictive note yet: nothing above is a vehicle for giving Lloyd,
Maria, or Edie a scene ahead of `I1`'s own rules. Edie does not appear in
this Part at all.
