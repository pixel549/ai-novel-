## How to use this file

Same job `H1` did for Region I, now for Region II, with one structural
difference `H1` didn't have to handle: Region I had no thin site to carry
a Chalice-Gifts section for, and this region does — `T1` is already built,
live, and reachable (not merely a flagged candidate). That changes this
file's Chalice-Gifts section from inert to a pointer rather than a second
worked example; see below. Everything else follows `H1`'s own split: the
ordinary and documentary objects the lead web and the locations already
assume exist (an archive's request slip, a rooming house's own ledger, the
specific prop behind Wick's tell), the city's native-Arcana register (same
ceiling as the valley's, sharper edges), and the weapons this region's
people actually carry — rail and mill tools, not an armoury, same
discipline `H1` held for mine tools. Hand a PC-facing item or weapon
description to players directly; keep the Arcana and Chalice-Gifts
sections DM-only where noted, same split `PLAN.md` draws between `B`
(players) and everything else (DM).

**Session default — D-34 (`DECISIONS.md`).** None of the specific items,
weapon archetypes, or the Chalice-Gifts cross-reference below are named on
the page. `R2a`, `R2b`, and `T1` each name or imply a prop this file had to
build out (the archive's own paperwork, a rooming house's ledger, the
concrete shape of Wick's charity, the city's ordinary weapons register) —
logged here rather than decided silently, the same way `G2` invented its
archetypes.

## Arcana in Vantry

Per canon §5 and `C2`'s Arcana practitioners entry, Arcana in a city this
size is exactly as real, uncommon, and mostly weak as it is in the valley —
the ceiling doesn't rise just because the population does. What changes is
the cost of being noticed: Region I's Unregistered Arcana Practitioner
worked quietly because nobody was looking very hard; Vantry's own version,
`G2`'s Lodging-Row Spark, works quietly because the stud book is a filed
document three streets away, not a rumour. The four gifts below are the
same four `H1` named for the valley — this file doesn't invent new
categories, only restates the city's sharper edge on using them.

- **Hearth-, Ease-, Mend-, and Find-work.** Identical in kind and ceiling to
  `H1`'s own entries; see that file for the full description of each.
  Mend-work's hard limit (no regrowth, no disease cure, inherited from
  Maria's own per canon §2) binds here exactly as it does there.
- **What's different here.** A Vantry practitioner who uses a gift openly
  risks the specific, local consequence `G2`'s Lodging-Row Spark is built
  around: not a vague social cost but a documented one, since the
  archive's stud book (below) is proof that this exact kind of person has
  been catalogued before. A DM running this archetype in the city should
  let that specificity sharpen every scene — "someone could look you up"
  reads very differently once the party has seen the actual book that
  would hold the entry.
- **Find-work and Reveal A.** As in Region I, a PC with this gift gets no
  mechanical shortcut to any of `R2b`'s three reveals — all three already
  have enough routes without one. At most, colour: a character who's had
  this knack since childhood might say, once, that the standing archive
  "pulls" at them the way a locked room does, which a DM can let land as
  atmosphere pointing toward Reveal A without it standing in for any of
  that reveal's actual routes.

`(SYS?)` tier: all four stay low-tier and non-combat, same as `H1`; nothing
in Vantry raises the ceiling.

## Chalice-Gifts

**DM-only.** Region I's Compendium kept this section inert because no
thin site existed there to activate it. Region II is different: `T1-the-
foundation.md` is built, open, and reachable the moment `R2b`'s Reveal A
Route 3 puts a party on the surface above it. This file does **not**
duplicate that work. `T1` already carries its own full account of how the
chalice at node 4 is reached, how a gift is built live at the table (per
`S1`'s five-step procedure), and why nothing is pre-assigned — read `T1`
directly rather than looking here for a second version.

What this section exists to do instead is keep three things straight for
whoever is running this Part with the Compendium open rather than `T1`
itself:

1. **This is the only live chalice in the campaign so far.** `H1`'s "Sure
   Footing" (Region I) was explicitly a teaching example, never assignable.
   `T1`'s own chalice is the real thing — a PC who drinks there gets a
   permanent gift and an equally permanent cost, built fresh, per `C3`'s
   D-13 and never drawn from either file.
2. **The Tank-Four Remnant (`G2`) is not this chalice, and the reverse.**
   `G2` is explicit that its remnant, if a DM uses it at all, is confined
   to the burned laboratory's own footprint and has no path down to `T1`'s
   site. A DM reading this Compendium entry while also holding `G2` open
   should keep that boundary exactly where both files already drew it —
   nothing here blurs it further.
3. **Nothing above requires a party to go under at all.** Per `C3`'s own
   standing instruction and `T1`'s "Decline is not a failure state": a
   party that finishes Part II without ever finding the stair has lost
   nothing this file considers a reward.

`(SYS?)`: no stat block accompanies any of this, for the same reason `H1`
gave — this is a pointer to where the mechanism lives, not a second menu.

## Items

Ordinary and documentary objects the Part's scenes already assume exist.
Player-facing except where marked.

**The stolen intake register.** Decades of names, dates, and dispositions
in the same ledger-style hand `source-bible.md` attributes to the Fourth
Mercy's own record-keeping — the document Reveal A's Route 1 and Route 2
both turn on (`R2b`). Filed at the standing archive, legally viewable, and
physically unremarkable: a heavy, water-stained volume that looks like
every other civic ledger on its shelf until it's opened. A DM can hand a
page of it to players directly once a scene reaches the archive — it's
meant to be read, not just summarised, same instruction `H1` gave the
buried survey.

**The stud book.** A separate, older volume tracking Arcane bloodlines
across six decades, cross-referenced to the intake register by a code
neither book explains on its own page (`source-bible.md` → Places). Reveal
C Route 2 checks this book's own dates — cold at ch. 18's exposure, never
resumed — without needing to ask anyone a question. Treat it as a second
prop alongside the register, not a restatement of the same one; a party
that finds only the register has not yet found this.

**Sixty years of extraction files.** Case folders, one per subject, ending
"result negative, subject retained" or "...subject not recoverable"
hundreds of times over (`source-bible.md`). Too many to read in full at
the table — a DM can let a party sample a handful, Corde Ashby's own
practice (`R2b`), rather than narrating all sixty years. This is where the
horror actually lives in this file's own register: catalogued, not lurid,
per canon §7.

**A civic request slip.** The single sheet of paper standing between a
party and all three documents above — name, date, reason for request, one
clerk's signature. Hester Combe fills it correctly without hesitation and
has clearly done this before, for the handful of people who've ever asked
(`R2b` → Reveal A, Route 1). The obstacle this Part keeps pointing at isn't
the slip, it's that almost nobody files one; a DM should let the slip
itself be trivially easy to complete, so the point lands rather than
getting mistaken for a bureaucratic puzzle.

**The broadsheet's photographed plates.** Corde Ashby's own archive,
filed with more care than the city keeps its own copies (`R2b` → Reveal A,
Route 2) — the original glass-plate negatives of the stud book and
extraction files, run as photographs specifically so no compositor's word
could be disputed (`source-bible.md` → Factions). A party shown these is
looking at the same evidence the register holds, framed for publication
rather than filing; useful where a scene wants the documentary weight of
Reveal A without a trip to the archive itself.

**Ress Tannery's rooming book.** The Shuttle's own ledger — rent paid
through the week, who's three to a room, who's between postings
(`R2a`) — the model for this region's version of Nessa's slate (`D1`/`H1`):
a short, specific, DM-visible list, never a number, and never read cold by
a PC, since Ress keeps it in his own shorthand the same way Nessa does.
Where Nell Quane's room being "still paid through the week" (`R2b`) is
first established as a concrete fact rather than a rumour.

**A debt settled, in writing.** The physical half of Wick's tell (`R2b`'s
"The Quiet Help" set piece): a single cleared slip or chit — a rent
receipt marked paid, a placement letter, whatever the specific kindness
needs — handed over before the question the party actually came to ask.
Per `R2b`'s own discipline, this is never a bribe and never framed as one;
it's a prop for a DM to describe concretely rather than summarise ("he
hands over a receipt, already signed") so the scene's discomfort lands on
the object itself, not just on Wick's manner.

**A shelter roll.** Any Mercy House's own list of who's slept there and
for how long, names crossed through for reasons ranging from found work to
nothing anyone wrote down (`R2a`). Reveal B Route 3 turns on a sister or
brother checking this list for Nell's name, not on any hidden second
document — the roll is exactly what it looks like, which is the point
`R2a` already makes about this location.

**A hidden candle stub.** The concrete prop behind `G2`'s Lodging-Row
Spark (or Nell Quane herself, before her fate is decided): a stub lit
without flint or match, kept short and used behind a turned back rather
than openly. Worth handing to a player directly only if their own
character is the one with the gift — otherwise it's colour a DM describes,
not an object anyone else picks up.

**Yard crew tools.** Coupling pins, a shunting pole, a platform lamp —
Coal Drop Yards' own ordinary kit (`R2a`), included here because `R2b`'s
Pest Pressure Clock (the Rail-Cut Lingerer, `G2`) gives a DM reason to put
a party near the cutting with nothing better in hand. Prop only; no
combat function beyond what `H1` already established for mine tools of the
same improvised kind.

## Weapons

Same discipline `H1` held for Region I: this is an industrial city, not an
armoury, and most of what's listed here is a tool first.

**Mill and yard tools (shuttle-pick, coupling pin, a shunting pole).**
Improvised before they're ever weapons, same register as `H1`'s mine
tools — someone reaching for the nearest heavy thing, not a trained
combatant. `(SYS?)` tier: low; favours intimidation and improvised damage
over any trained bonus, identical to `H1`'s own entries of this kind.

**A watchman's cosh.** Standard-issue for whoever nominally employs
Ascension House's own watchman (`R2a`), and functionally identical to
`H1`'s company gatekeeper's cosh — short, leather-wrapped, meant to
discourage rather than injure. None of this Part's lead-web routes
require a fight with anyone carrying one; per `G1`'s own precedent, if
it's drawn at all, that's the scene going wrong, not the scene's intended
shape.

**An Attrition-surplus revolver.** The same Commonwealth-wide surplus `H1`
already describes (canon §5) — plain, worn, unremarkable to own and not
unremarkable to draw. A rail yard or lodging-row veteran carrying one fits
this city exactly as well as it fits the valley. `(SYS?)` tier: the one
weapon in this file capable of lethal force at range — treat every
appearance as a serious escalation, never as flavour.

**A trench knife.** Attrition-era, double-edged, carried quietly by
veterans who don't talk about where they got it — identical to `H1`'s own
entry, no regional variant needed. `(SYS?)` tier: low-to-mid, close range
only.

**What the Church carries: nothing.** Per `R2b`'s own discipline for
Brother Wick and every Mercy sister or brother in this Part, none of the
Church's own people in Region II carry or draw a weapon of any kind — the
institution's menace, per the tone contract, lives entirely in content,
never in staging, and arming a Church face here would be the staging
mistake `R2b`'s DM Notes already warn against. A DM reaching for this file
to give a Mercy House scene an edge should reach for dialogue, not an item
entry; there isn't one here on purpose.

## DM Notes

**Nothing above needs a fight.** Per `G2`'s own standing note and `A1`
pillar 1: every weapon here is either explicitly non-lethal by design (the
cosh), an escalation to treat seriously (the revolver), or something
nobody in Region II's lead web is built to need (everything else, the
Church's absence most of all). Reach for combat because the table wants
it, not because an item entry exists.

**Items are props, not a reward track.** Same restraint `H1` held: no item
above is meant to make a PC mechanically stronger. A DM looking for a
"found item" beat to reward a scene should reach for information or
standing (a favour, a route opened, per `F1` §6) rather than an object from
this list.

**The Chalice-Gifts section is a pointer, not a second file.** If a player
asks whether their character can drink from a chalice this Part, the
honest answer is yes, but only at `T1`, and only by going there and finding
it — this file supplies no shortcut, no pre-built option, and no
Region-II-specific variant of the procedure `T1` and `S1` already own.

**Nothing here changes `R2a`/`R2b`'s restriction on Edie.** None of the
items above are hers to use as a scene-building excuse ahead of `I1`'s own
rules — the iron cabinet, the knot-cord, and Edie's own ledger are all
already described in `R1a`/`H1` and `R2a`; this file adds nothing that
would put her in a speaking scene early.
