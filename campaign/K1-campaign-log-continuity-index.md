# K1 — CAMPAIGN LOG & CONTINUITY INDEX

*Reader: DM, especially an AI DM. Two tools, not lore: Part 1 is a
continuity index — where to look things up without re-reading five files.
Part 2 is a blank log template — what to write down after every session so
the next one doesn't start from nothing. Cites every campaign file by ID
rather than restating any of them; `A2-dms-guide.md` §1 is this file's own
reason for existing ("treat the absence of `K1` as a real gap to patch with
a plain text note, not a reason to re-derive continuity from nothing each
time").*

## Part 2: Campaign Log Template

One entry per session, appended to this table's own copy of this file (or
a separate running note — the shape matters more than where it lives).
Read the most recent entry, plus `A1`, `C2`, and the live Part's files,
before starting the next session (`A2` §3's "read before running"). Keep
each entry short enough to actually reread; this is a log, not a write-up.

| Field | What goes here |
|---|---|
| Session # / date | table's own numbering |
| In-game date | days/weeks since `A1`'s anchor (a year after ch. 25) or since the last entry, per `F1` travel times |
| Party | PC names/concepts only — no stats live here |
| Current base | which of `D1`'s bases/alternates or a later region's foothold, and its upkeep tier (Rough/Ordinary/Standing/Specialist, `F1`) |
| Where / Part | region, site, which Part's lead web is live |
| Summary | 3–5 lines: what happened, in table-time voice |
| Clocks moved | which of `C2`'s six (or a regional Pest Pressure instance), before → after, and why |
| Heat / Notoriety | per faction/region, `F1` §5 — note what caused the change |
| New facts established | any DM call made on the fly per the index note above; binding from now on |
| NPC status changes | injured, dead, missing, revealed, made a contact (never a recruited ally for Lloyd/Maria/Edie/Vail — `I1` §A) |
| Chalice gifts taken | which thin site, recipient, the bespoke ability/cost pair built live (`S1`'s procedure, `C3`'s D-13 rule) |
| Open threads touched | cite `hooks.md` numbers; note resolved vs. still open |
| Next session setup | the hook the table is walking toward |

## DM notes

**This file holds no world facts of its own.** Everything in Part 1 is a
pointer; if an index entry and the file it points to ever disagree, the
file it points to is correct and this index should be fixed to match, not
the other way round.

**For an AI DM specifically** (`A2` §1's own flag): a session with no log
entry to read back from a previous one has no memory of what happened. Ask
the table for the last entry, or for a plain summary, before running a
session that isn't the first.

**Logged facts are binding, not advisory.** A DM call made at one table's
session and written into that table's log is that table's canon going
forward — it does not change `DECISIONS.md` or any other table's game, and
a different table making a different call for the same undecided question
is not a contradiction.
