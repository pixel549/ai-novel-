# I1 — DRAMATIS PERSONAE

*Reader: DM. Builds on `A1-campaign-brief.md` and `C2-factions-clocks.md` —
read both first; this file does not restate the premise, the timeline
anchor, or the cameo restraint every Part file has been holding until now.
Cites `source-bible.md` → People/Rules, `hooks.md`, and `novel/canon.md`
§§1–3, 6, 8 throughout. This file is the one every R-file from `R1b` onward
has been waiting on; its rulings below are binding on every Part, retroactively
and forward, replacing each Part's own provisional "until `I1` exists" line.*

## How to use this file

Section A sets the only rules for running Lloyd Hale, Maria Vesk, Edith
Marrow, and Ondine Vail as NPCs — read it before voicing any of the four,
whichever Part the table is in. Section B is canon's who-knows-what table,
condensed for table use. Section C is a one-page index of every other
named, recurring NPC the campaign has invented so far, organised by region,
so a DM running out of order isn't re-reading five Part files to remember
who Winifred Sorrel is.

## A. The Three, and Vail: Cameo Rules

### The cameo tiers

Three levels, cumulative — a character cleared for Tier 2 is also cleared
for Tiers 0 and 1.

- **Tier 0 — Background mention.** A name on a report, a wanted notice, a
  rumour, a figure named in passing. No confirmed sighting, no dialogue.
  Safe everywhere, always.
- **Tier 1 — Confirmed, silent presence.** The character is actually there
  — a face across a courtyard, a name on a household roster, a resemblance
  someone remarks on — but still never speaks on the page. This is what
  every Part file has run by default since `R1b`.
- **Tier 2 — A scene, with dialogue.** Rare, and only for the two
  characters this file opens it for below (Edie, Vail). One scene, not a
  standing presence; the table leaves it with no more than a real
  conversation bounded by canon would give them.

**Across every tier, permanently:** no scene resolves a who-knows-what gap
(Section B), recruits one of the four as a running ally, fights them,
heals or harms them in a way the novel doesn't already cover, or changes
anything `A1`'s timeline anchor or `DECISIONS.md` D-1 fixed. A PC can learn
things *about* them that a stranger plausibly could. A PC cannot learn
things only Lloyd, only Maria, only Edie, or only Vail knows.

### Lloyd Hale — Tier 0/1 only, campaign-wide

No Part file has ever placed Lloyd anywhere closer than a wanted notice
(`R1a`) or a rumour and a resemblance (`R3a`), and this file doesn't open a
location none of them built. That restraint stands for the whole
campaign, including its ending — `R5b` already closed Part V to no
appearance at all. If a table's own play somehow puts a PC in a room with
him anyway, hold Tier 1 at most: no dialogue.

If a DM ever judges a specific scene needs more than that (this file does
not pre-build one), bind it to canon §1: short sentences, concrete nouns,
no metaphor; answers questions literally, including rhetorical ones; gets
shorter, not louder, under stress; never organises or directs other
people, even the most experienced person in the room. He will not discuss
his second arm, his five weeks in Carrowgate, or his intent toward Crane —
closed, canon §6 — and deflects a question that gets close with a joke
rather than a lie. No numbers here; if a fight becomes unavoidable, he's
dangerous (a labourer's build, a prizefighter's reflexes) and the scene
should end before stats would matter — archetype and tier only, generated
live same as any other NPC, per `PLAN.md`'s own conventions `(SYS?)`.

### Maria Vesk — Tier 0/1 only, campaign-wide

Always with Lloyd (`A1`); the same restraint, for the same reason — no
Part file ever built her a location closer than that. Voice per canon §1:
compound-complex sentences that loop back on themselves; self-doubt named
aloud, not implied; warm, quick humour, especially at the worst of it;
never cruel, cold, or sanctimonious. If a DM's own scene goes further than
Tier 1, her native Arcana is archetype-only and fixed to canon §2's list —
healing (slow, costs her hours, no regrowth, leaves her useless after),
light, a single fire burst (several minutes to recharge), lightning (she
hates using it), steadying — nothing beyond that list, and never a chalice
ability (she refused one on the page). She doesn't know, and won't claim
to know, whether the Salts ever strengthened her gift; the book leaves
that open and so does this file. She doesn't know what actually filled
Lloyd's arm in ch. 3 either — if asked, she describes healing him, because
that's what she believes she did.

### Edith "Edie" Marrow — unlocked for one Tier 2 scene

Region II, Ferrick's household, Vantry — the fixed, on-page presence
`R2a` and `R2b` both built and then deliberately left silent, pending this
file. A DM may now run **one** scene with Edie speaking, inside that
household, in character.

**Voice** (canon §1): flat, brief, unornamented; trade vocabulary used
without translation (spoil, shoring, face, breach); states conclusions and
omits her reasoning unless asked; no self-analysis, no rhetorical
questions aimed at herself, no hedging; doesn't name a feeling, lets it
show as an observation about what's broken or missing instead.

**What she'll talk about, freely:** household security, Ferrick's
sincerity and his limits, the practical cost of things — her ledger habit
(`hooks.md` #14) is a good model for how she'd actually itemise a party's
own expenses if she ever had reason to. **What she won't, under any
framing:** Reyne's death (never told to anyone; permanent, canon §6), the
ninety-one sappers (she mentions them to no one outside ch. 24, and this
file extends that silence to every table use of her), or her Still Mind as
anything beyond an instinct she doesn't explain and didn't ask for.

**The Still Mind, if it matters in the scene.** It covers violence
only — a person's decision to hit someone, nothing else. It does not fire
on an accident, a collapsing shelf, a dropped tray, or any danger without a
person's violent intent behind it. *(This is this file's own operating
default for any table use of the ability, not a ruling on ch. 23's text —
see `DECISIONS.md` D-31. R-5 stays open for Jake; it just doesn't reach
this file.)* It does not make her faster, harder to hit, or safer — if
she's struck by something she "knew" was coming, let her get hit anyway;
the gap between knowing and acting is the whole point (canon §2, §8), and
a scene that uses it to save her cleanly is being run wrong.

One scene. She does not become a recruitable ally, does not leave
Ferrick's employ, and does not get pulled into a PC's business beyond
whatever the one scene was about.

**A worked example.** A party investigating Nell Quane's disappearance
(`R2b`) asks the household for the visitor log Edie keeps. She hands it
over without being asked twice — it's not sensitive, she has no reason to
hide it — and answers exactly what's asked: who came, when, nothing about
why unless that's a separate question. If a PC asks whether she's ever
been wrong about someone she trusted, she says "once," names no one, and
offers nothing further — not a deflection, just the whole answer she's
giving. Pressing harder gets the same sentence again, flatter each time,
until the table reads that this door is shut and moves on; it never gets
shut rudely, and it never opens.

### Ondine Vail — unlocked for one Tier 2 scene, heaviest discipline in this file

Region III, the Sanctum, Carrowgate — the fixed presence `R3a` built and
then explicitly reserved for this file ("do not run her as a speaking NPC
with anything resembling a scene... until `I1` exists"). A DM may now run
**one** scene with Vail speaking, at or near the Sanctum.

This reproduces canon §3's writing rules as table rules, verbatim in
substance, because the failure mode — writing menace into her delivery —
is exactly as easy to fall into at a table as on the page:

- She never lies. An awkward question still gets answered.
- She never lowers her voice. No murmuring, no waiting until alone, no
  glancing at the door.
- She never threatens, not even by implication. A PC who refuses her is
  not punished, followed, or warned.
- She never gets angry and never goes cold. Being contradicted doesn't
  change her warmth.
- She answers direct questions directly. If a PC doesn't ask the right
  question, that's on the player, not a withholding on her part.

**Delivery bans for the DM**, same source: no smile that doesn't reach her
eyes, no meaningful pause before an answer, no lingering in a doorway, no
eyes described as cold, flat, hard, or unreadable, no room's temperature
changing, no PC "feeling a chill." If the scene would still read as
unsettling spoken aloud in a warm, pleasant voice, it's being run right. If
it needs staging to land, it's wrong — rewrite it, don't perform it harder.

**What she'll discuss:** the Fourth Mercy's existence and purpose, if asked
sincerely and directly — she believes in it and says so, exactly as in ch.
13. **What doesn't move:** her own position, the Sanctum's operations, or
anything `DECISIONS.md` D-1 already fixed (untouched; she's promoted; none
of it is under dispute from her side). She will not confirm, deny, or
speculate about Lloyd or Maria's current situation beyond what's already
public knowledge — her affection for Maria is real, which is exactly why
she won't use a PC as a way to find her. Asked directly, she says plainly
that she hopes Maria is well, and leaves it there.

One scene. She is not built as an antagonist anywhere in this campaign and
nothing here changes that — there is no defeat, flight, or capture outcome
for Vail. A table that tries to force one should get the same answer `A2`
already gives for storming the Sanctum itself: this isn't that kind of
scene.

**A worked example.** A party with real, specific evidence (not rumour —
something from `hooks.md` #3's standing archive, say) requests an audience
and asks Vail outright whether the Fourth Mercy exists. She says yes, in
the same room, at the same volume she'd use to discuss the bread queue,
and tells them what it is and why she believes in it, for as long as
they're willing to listen — delivered warmly, not performed as a
confession. If a PC asks whether she feels any guilt, she says no, and
means it, and explains why in the same plain terms canon §3 gives her at
ch. 13. Nothing about her manner should read as a reveal; the horror, if
the table feels any, has to come from what she actually said once the
scene is over, not from how she said it.

### Ivet Hale — formalising R1a's existing allowance

Region I, Callow Ford (or wherever `A1`'s anchor has resettled her by the
time a table arrives — recovered, on clean water). Already a speaking NPC
per `R1a`; this file states the limit explicitly rather than leaving it
implicit. She knows nothing of Lloyd's second arm, his institutionalising
at twenty-two, or his intent toward Crane (canon §6), and nothing she says
should imply otherwise, even glancingly, even under a PC's pressure. She
can speak warmly and plainly about her own illness and recovery, about
Lloyd as her son rather than as anyone's protagonist, and about the
valley's water — a mother's register throughout, with no awareness of
anything he's ever hidden from her.

## B. Who Knows What (table use)

Condensed from canon §6. The three columns show what Lloyd, Maria, and
Edie each know by the book's end (ch. 25) — not what a PC can learn. Three
rows are permanent gaps between the leads themselves, never resolved even
among the three; the rest are things the three came to share with each
other but that stayed, and stay, closed to everyone outside them. **No
row in this table is ever learnable by a PC, at any tier, regardless of
which column says "yes."**

| Fact | Lloyd knows | Maria knows | Edie knows |
|---|---|---|---|
| Lloyd has a second, ethereal arm | yes (ch. 5) | never told | never told |
| What the ch. 3 "regrowth" actually was | yes (ch. 6) | never told | never told |
| Lloyd was institutionalised at 22 (Carrowgate, five weeks) | yes | never told | never told |
| Edie killed Colonel Reyne | yes (ch. 24) | yes (ch. 24) | yes, always |
| Anse Duley was taken by the Fourth Mercy | yes (ch. 14) | yes (ch. 14) | never |
| Lloyd intended to kill Crane | yes (ch. 1) | yes (ch. 20) | yes (ch. 24) |

A PC can discover public facts around these (Lloyd is wanted; Maria left
the Church; Edie served under Reyne) without ever closing the gap itself.
Treat a player's clever deduction that lands on the truth as something no
NPC will confirm — the gap isn't guarded by anyone's ignorance of the
question, it's permanent regardless of how good the question is. The
first three rows stay closed between the leads too, which is why Section
A binds Lloyd, Maria, and Edie each to their own silence on them; the last
three are shared among the three already, which is why Section A's limits
on Edie (Reyne, the ninety-one) and on Ivet (Lloyd's arm, his
institutionalising, his intent toward Crane) matter just as much even
though those facts aren't secrets inside the trio.

## DM notes

**This file doesn't retroactively edit any Part.** `R1b` through `R3a`'s
own restraint stays correct history for how those Parts were written; this
file only lifts the "pending `I1`" clause each of them left open, for
Edie and Vail specifically, and confirms the rest stays shut for good.

**A Tier 2 scene is a destination, not a default.** A session can and
usually should go by without one. Save Edie's and Vail's scenes for a
moment the table has actually earned — a specific question worth asking,
not a stop on a checklist — the same restraint `A1` pillar 5 asks for
everywhere else (offer neglect over spectacle).

**Apply the cost test here too** (`A1` pillar 4, canon §8). A scene with
Vail especially should cost the party something to have had — not in
loot or information withheld, but in how little the conversation moves
her, the Sanctum, or the Church. That flatness is the point, not a bug in
the scene.

**An AI DM asked to run a Tier 2 scene it hasn't planned for** should
treat it the way `A2` already treats an unsupported ruleset number: say so,
and offer the Tier 0/1 version instead, rather than improvising dialogue
this file hasn't bounded.

**R5a's deferred question, answered.** `R5a` left open whether this file
or `R5b` would ever use one of the three at the very end of the campaign.
`R5b` has since closed Part V itself to no appearance at all, and this
file doesn't reopen that — Lloyd and Maria stay Tier 0/1 for the whole
campaign, endings included. If a specific table's own ending calls for
something more (a last sighting after the credits, so to speak), that's a
one-off the DM builds for that table, bound by every rule in Section A
above; it is deliberately not pre-built here, the same restraint every
Part file has held since `R1b`.

**One scene really does mean one.** If a table gets a second Tier 2
scene with Edie or Vail out of genuine play rather than a DM's shortcut,
that's a judgement call the table's own DM is making in the moment, not
something this file licenses in advance. The value of "one scene" as a
rule is that it forces the DM to wait for the question worth asking
before spending it.
