# T1 — THIN SITE 1: THE FOUNDATION

*Reader: DM. Builds on `C3-the-salts-as-background.md` (the thin-site rules
this file is the first to use) and `R1b-larrow-valley-leads-antagonist.md`
(STATUS.md's formal dependencies) — read both first. Also cites
`R2a-vantry-overview.md` and `R2b-vantry-leads-antagonist.md` for the
surface location this thin site sits beneath (Ascension House's ruin,
Vantry) and for `D-21`'s standing rule that the ascension work has not
resumed anywhere in the city; this file does not reopen or contradict that —
see "Why This Isn't Wick's Problem" below. Cites `S1-surface-adaptation.md`
for the chalice-ability build procedure and `hooks.md` #4, #11, and #12
directly. No `campaign/system/` ruleset exists yet (Q-1); every mechanical
value below is `(SYS?)` — this file fixes what the site is and does, not
what it costs on a character sheet. Per `C3`, this is the one place in the
campaign where the ruleset's actual Salts loop (anchor chalice, hub,
bail-out, Tokens, no fast travel, mutation) runs unmodified; `S1`'s surface
adaptation does not apply past the threshold below.*

## How to Get Here

Reveal A, Route 3 of `R2b` already puts a party on the surface above this
site: a daylight walk through Ascension House's burned shell, the older
stone foundation reading as a different, earlier building under the new
brick's char. That walk ends at the edge, deliberately — `R2b` §7 is
explicit that going under is this file's job alone.

**There is no hydro here, no reagent, no steam room.** Per `C3`'s own
definition, a thin site is a place where the Salts has worn close enough to
the surface that none of that apparatus is required, and this file invents
its own version of the moment, rather than borrowing Stillwell's: the barred,
below-grade window `source-bible.md` already places at Ascension House —
the one that shows a pale standing gleam that isn't lamplight — is not a
window into a flooded sub-cellar. It is a window into this. A party that
looks through it long enough, or a party that simply decides, the way `C3`
says a chalice gets decided into the room, to go around to where a door into
that gleam ought to be rather than isn't — finds one. Nobody searches their
way down here by rolling well enough. They get here by choosing to treat the
char and the fallen brick as though a door is already standing open in it,
the same rule `C3` gives the chalice itself, extended to the whole site
before anyone reaches the chalice at all.

Offer this moment plainly and once. A party that declines it has made a
completely valid choice (`C3`, `A1` pillar 2) and this Part continues exactly
as `R2b` already describes without it.

## The Loop, As-Is

Everything below runs the ruleset's actual Salts-loop rules unmodified —
anchor chalice, hub, Token economy, bail-out, no fast travel, mutation — the
one place in the campaign this is true (`C3`; `S1` "Mutation and the Salts
Loop"). None of `S1`'s surface replacements (crowns and favours, safehouses,
flight/capture/recovery, real travel) apply past the threshold above. `(SYS?)`
for every number this needs: anchor cost, Token count, bail-out trigger
conditions, and mutation thresholds all wait on `campaign/system/` landing.
Run the loop the way the novel's own chapel runs it — time inside doesn't
track time outside, a run is taxing, injuries taken here are real on
surfacing and may heal wrong — until the real ruleset tells you otherwise.

## What's Down There

Not the chapel. `C3` is explicit that nothing says a different site opens
onto the same dreamscape room, and this file takes that instruction
seriously: the chapel-shaped gallery is Stillwell's, personal to whoever
goes under there. What's under Ascension House is older and keeps a
different kind of wrongness.

**Session default — D-28 (`DECISIONS.md`).** `hooks.md` #4 leaves this
genuinely open — "whatever was on that ground before the chapel is still
there," no further specification. This file decides the minimum needed to
run it, in the same withholding register canon uses for the Fourth Mercy's
added catechism line (`hooks.md` #6, still untouched): there is no name for
this place, no founder, no doctrine, and — this is the part that matters —
nothing here is Fourth Mercy work at all. It predates the Church's ownership
of the ground by a margin nobody currently alive can measure, and the
Church's own ascension programme, sixty years running, never found it,
built on top of it, or used it; the brick went up over stone that was simply
already there, the way builders in every century put a foundation on
whatever's load-bearing without asking what it used to hold up. Vail's own
sincerity about the Fourth Mercy's purpose is real and untouched by this —
she genuinely doesn't know, any more than the Church's doctrine does.
**This file commits to no further resolution than that.** A DM who wants
more should invent it consistent with the above, not look here for an
answer the hooks file never had.

Instead of a stable architecture, treat every room below as provisional —
not candles moved or a column added, the way Stillwell's chapel varies, but
rooms that don't keep their own size. A corridor a party remembers as short
reads long on the way back. A chamber two people both stood in describes a
different ceiling height to each of them, and neither is lying. This is
`hooks.md` #12's nineteen-foot shaft (surveyed twice at twelve feet, read
nineteen on the actual descent) taken as a standing principle rather than a
one-off flavour beat, exactly as the hook itself proposes: distance and time
down here don't have to agree with measurement, and a DM can use that
honestly, describing without ever explaining why.

## The Site

Four nodes. This is a short, compact delve — `PLAN.md`'s own target for a
thin site — not a dungeon with a floor plan a party needs to map correctly.
Run it as a sequence a DM narrates through rather than a grid; let the
wrongness above excuse any inconsistency in how long a party spent getting
from one node to the next.

### 1. The Stair That Wasn't Brick

The threshold itself: stone steps, worn in the middle the way steps wear
under centuries of use, not decades — directly contradicting everything
else about this building, which is new brick over old ash. The air changes
before the stairs do; it is colder going down than it has any right to be
this close to a fire-gutted ground floor. No decision point here, only the
first dose of the register: describe, never signpost. If a player asks
whether this is really happening, that question is the scene working.

### 2. The Long Room

A chamber longer than Ascension House's own footprint should allow —
`hooks.md` #12's device, used for the first time. Bare stone, no furniture,
no markings, and a floor that is not quite level in a way that never quite
resolves into a direction. Somewhere in this room is where the Salts'
actual pull is strongest; a party that stops moving for any length of time
here finds that length of time is not what they'd have guessed.

**Encounter (optional).** `hooks.md` #11's wire-frame creature — thin,
jointed, no face, moving by flickering rather than walking, dissolving to
salt mist if pressed — is flagged in the hooks file itself as ready-made for
exactly this use. It does not hunt with intent; like the Collapsed-Tunnel
Lingerer archetype (`G1`), it investigates sluggishly and loses interest
once a party puts distance between themselves and it, but unlike that
archetype it belongs here, not to weather and disturbed ground — it is
native to this place the way the Lingerer is native to the mine.
`(SYS?)` tier: low; a scene, not a set piece. Use it once, briefly; a second
appearance should feel like the same thing noticing them again, not a
restocked encounter.

### 3. The Gleam

Where the barred window's light actually comes from, approached from the
inside: not a fire, not a lamp, nothing with a visible source — a standing,
pale gleam against one wall, the shape `source-bible.md` already describes
from outside it. Up close it resolves into nothing clearer. Something,
once, "moved nothing like a man walks" near here (`hooks.md` #4) — if a
party lingers, that's the moment to let them feel watched rather than show
them anything. Per `PLAN.md`'s tone contract: withhold lore, describe, treat
every source (including the party's own eyes) as unreliable. If a player
asks what it is, the honest table-time answer is that nobody in the
Commonwealth, including Vail, could tell them.

**What actually happens here.** Nothing, by default. This is the chamber a
DM can return to later in the campaign — once, maybe, if a Part needs a
reason to send a party back under — without ever cashing it out. A gleam
that gets explained stops being this file's.

### 4. The Chalice Room

Smaller than node 2, and — unlike everything else in this site — it holds
still the moment someone decides to look at it the way `C3` requires: a
lead vessel on a plain stone shelf, no pedestal, no carved depression,
because this isn't Stillwell's chapel and shouldn't borrow its furniture.
It is there because someone in the room decided it should be, exactly as
`C3` states, nowhere else in this file. See "The Chalice," next.

## The Chalice

Per `C3`'s D-13 and `S1`'s build procedure: this file does not pre-build a
gift. The same restraint `H1` held for Region I applies here with the lid
finally off — a PC who drinks at node 4 gets an ability bespoke to them,
built live, following `S1`'s five steps (name an ordinary function; invert
or extend it once, specifically; pair it with an equally specific permanent
cost using the same function; check it against Lloyd's shape; never reuse
Lloyd's own pair). `H1`'s "Sure Footing" is explicitly not available to
assign — it exists only to teach the shape, and this is the file where that
teaching pays off.

**Running the moment.** Ask what the character reaches for, physically — a
hand, an eye, their voice, their sense of where they are in a room — and
build from there, not from a menu. The gift should feel earned by the
specific person at the table, not selected from this file. Decline is
exactly as valid an outcome as acceptance (`C3`; Maria's own on-page model);
a party that walks out of node 4 with nobody having touched the chalice has
made the same choice she did, and this site does not punish it.

**Cost is not optional once a gift is taken.** `(SYS?)` for the exact
mechanical shape, but the content is not negotiable: specific, permanent,
and built from the same function as the gift, per `S1` step 3. A DM who
lets a player talk the cost down to something milder has written the scene
wrong — go back to Lloyd's own pair (an arm that reaches anywhere / can't
trust which arm answers) before finalising anything.

## Mutation and Injury

Per `S1`'s D-14, mutation stays Salts-side everywhere in the campaign except
here. This is the one site where it can trigger exactly as the ruleset
defines it, `(SYS?)` for the actual thresholds. Injuries taken past the
threshold are real on surfacing and may heal wrong, same as the chapel —
this is not the place to soften that for a first thin site. A DM who wants
this delve to feel lower-stakes than the novel's own chapel scenes has
misread `C3`'s own instruction not to do that.

## Leaving

Bail-out applies, unmodified, `(SYS?)` for the trigger conditions — this is
not the flight/capture/recovery rule `S1` built for the surface; that rule
does not reach past the stair. A party that bails out mid-delve surfaces
wherever the loop's own rules put them, with whatever they went in carrying
and nothing more; node 4's chalice does not travel with anyone who hasn't
already drunk from it, the same way Stillwell's never has.

**No fast travel back in.** Per `C3`'s own standing instruction against
letting a thin site become the loop by the back door: the stair at node 1
is the only way down, and the site is not a resource a party farms between
sessions. If a table starts treating this as a dungeon to return to for
gear, that's `C3`'s own flagged sign that Part II isn't giving them enough
reason to stay up top — fix that in play, not by closing the stair.

## Why This Isn't Wick's Problem

Per `R2b`'s D-21, nothing like Ascension House is running anywhere in
Vantry, and Brother Calder Wick's entire job is managing attention toward a
ruin that genuinely has nothing active in it. This file does not reverse
that. What's under the ash predates the Church by a margin nobody can date
and was never Fourth Mercy work — Wick doesn't know this site exists any
more than Vail's doctrine does, and a party that goes looking for an
institutional conspiracy down here is looking for something this file
deliberately doesn't contain. If a DM wants Wick to eventually learn of it,
that's a choice for a later session, not something this file assumes or
needs; as written, going under changes nothing about Wick's standing, his
tell, or what defeat, flight, or capture look like for him (`R2b` §6).

## Consequences

- **Region II's clocks.** Untouched by a visit here (`R2a`, `R2b`) unless a
  DM specifically routes the Pest Pressure Clock through disturbed ground at
  the ruin — plausible, since this site is, in effect, the deepest disturbed
  ground Region II has, but not required.
- **The chalice gift, if taken.** Permanent, per `C3`/`S1`, and belongs to
  the campaign going forward the same way Lloyd's arm belongs to the novel —
  carry it into every later Part a DM runs for that character.
- **The gleam at node 3.** Stays exactly as unresolved as it was found,
  unless a DM deliberately decides otherwise and logs that decision the way
  this file logs D-28 — don't let a later Part quietly explain it away.
- **What the surface notices.** Nothing, by default. Per the cost test
  (canon §8), this is the campaign's clearest case of a cost paid entirely
  by the people who went under and nobody else — no broadsheet story, no
  faction response, no change to the ruin's sensory tells as `R2a` describes
  them from outside.

## DM Notes

**This is the hardest register shift in the campaign so far.** Every
surface Part up to this point has run on the novel's own stance — clear-eyed
institutional neglect, menace delivered warmly, content over staging. None
of that applies past the stair. `PLAN.md`'s tone contract calls this out
explicitly: Bloodborne/Lovecraftian dream-logic, withhold lore, describe
don't signpost, treat every source as unreliable. A DM who runs this site in
the surface Parts' register — explaining the gleam, giving the wire-frame
creature a motive, resolving node 3 — has written the whole delve wrong, the
same category of mistake as giving Vail a smile that doesn't reach her eyes.

**Short means short.** `PLAN.md` sizes a thin site as a compact delve, not a
dungeon crawl. Four nodes is the whole site; don't pad it with a fifth to
make the descent feel more substantial. The chalice moment at node 4 is the
payoff this whole file exists to set up — spend the table's patience
getting there, not wandering an extra corridor first.

**Don't let the gift become a second Lloyd.** `S1` step 5 and `C3`'s D-13
are both explicit: nobody gets his pair, ever. If a built ability starts
reading like "an arm that passes through walls, but different," start the
procedure over from a different function.

**Decline is not a failure state.** A party that walks away from node 4
having taken nothing has finished this file exactly as successfully as one
that drinks. Nothing downstream requires a PC to have a chalice gift, and
nothing in any later Part assumes one exists.
