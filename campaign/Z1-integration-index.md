## 3. Final DM Checklist

### Before the campaign starts (once)

- [ ] Read `A1` in full. Not a summary — the premise, the timeline anchor,
      and the six pillars are load-bearing for every session after.
- [ ] Read `PLAN.md`'s tone contract once, and `A2` §2's table-use
      distillation of it.
- [ ] Run session zero per `A2` §4: pitch, character creation and hooks,
      lines and veils (`A2` §5 — do this as its own conversation), table
      logistics (who keeps the running note, per `K1`'s template).
- [ ] Hand out `B1` before character creation, not after.
- [ ] Decide where `campaign/system/` stands (Q-1). If the real ruleset
      isn't in yet, agree with the table that every number is
      archetype-and-tier only, resolved by narrative success/failure or a
      flat roll, per `A2` §3.
- [ ] If you have opinions on Q-2 through Q-5 or any `D-` default
      different from what's logged, decide now and note the change —
      every default is yours to overturn, and it's easier to overturn
      once, at the start, than to discover mid-Part that a file assumed
      the standing default.

### Before every session

- [ ] Read back the last `K1`-style log entry (or whatever running note
      stands in for one). This matters more for an AI DM than a human
      one — per `A2` §1, a session with no log entry to read has no
      memory of what happened last time.
- [ ] Read the live Part's two files (overview + leads/antagonist) if it's
      been more than a session or two.
- [ ] Check `C2` for whichever clocks are actually in play and decide, in
      one line, what moved since last time — per `A2` §1, say it out
      loud at the table.
- [ ] Decide, in one line, which base/safehouse (or recovery tier, if
      outside Region I) the party is currently using and what that's
      costing them, per `D1`/`F1`.

### Running a scene (standing discipline, every session)

- [ ] Apply the cost test before and after every scene (canon §8, `A1`
      pillar 4): what did this cost, and who paid it.
- [ ] Offer the quiet option alongside the loud one, not instead of it
      (`A1` pillar 5).
- [ ] Honour every telegraphed tell exactly, every time — Corlett, Wick,
      Pell, Vane, Ness, Prynne, and Vance's own question each have one;
      breaking a tell to serve a scene is always the wrong call.
- [ ] Church menace lives in content, delivered warmly. No ominous
      staging, ever — canon §3's delivery bans for Vail extend to Wick,
      Ness, Prynne, Anstey, and Vance.
- [ ] Never resolve a who-knows-what gap (canon §6) or push past `I1`'s
      cameo tiers for Lloyd, Maria, Edie, or Vail. One Tier 2 scene each
      for Edie and Vail, ever, and read `I1` §A first.
- [ ] Never invent a fact that contradicts `source-bible.md`, canon, or an
      existing file. If a player asks something nothing answers, make the
      same kind of defensible call a Phase 2 session would, say so as a DM
      call, and write it down — it's binding from then on (`A2` §3).
- [ ] Preserve player agency over the lead web — three routes exist so any
      one can be found first, not in sequence. A stalled reveal after a
      genuine attempt at all three is a failure state, not a bug to patch
      live (`A2` §1, §3).
- [ ] If going under a thin site comes up: offer the moment plainly and
      once; run the unmodified Salts loop past the threshold; the register
      shifts to Bloodborne/Lovecraftian the moment anyone crosses it;
      decline is never a failure state.

### Red flags — if you catch yourself doing one of these, stop

- Giving any sincere Church-adjacent NPC (Wick, Ness, Prynne, Anstey,
  Vance, or Vail herself) a smile that doesn't reach their eyes, a
  lowered voice, or any staging cue canon §3 bans. The menace is supposed
  to survive being read aloud warmly — if it needs performance to land,
  rewrite the line, don't perform it harder.
- Playing any of the six factions' people as a disguised villain. Every
  one of them wants something ordinary.
- Letting a thin site become a dungeon the party farms between sessions,
  or explaining what any of the three sites' unresolved elements (the
  gleam, the tally wall, the basin) actually are.
- Toppling an institution, resolving a who-knows-what gap, or giving a
  second PC Lloyd's own chalice pair.
- Inventing a hard number instead of marking it `(SYS?)` and resolving it
  the light way, per `A2` §3.

### If a table finishes Part V

The campaign's own ending is one of `R5b`'s five (or a sixth a table
improvised in the same shape) — there is no further Part queued, and
`PLAN.md`'s work queue is, as of this file, complete end to end. A table
that wants more has three options, none of which this file decides for
them: run the same five Parts again with a different party (a lead web's
three routes mean a different table will walk it differently); let Jake
write a Part VI under a new `R6a`/`R6b` pair following every convention
`PLAN.md` and this index describe; or treat the five Parts, the three
thin sites, and the several endings as the complete, finished campaign
they already are.
